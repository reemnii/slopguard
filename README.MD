# SlopGuard

SlopGuard is a Python tool that detects likely package hallucinations in code generated by AI coding assistants. It extracts package imports and install commands from Python and JavaScript/TypeScript files, checks package names against PyPI or the npm registry, and assigns a risk score based on the result.

## Features

- Supports Python (`.py`) and JavaScript/TypeScript (`.js`, `.jsx`, `.ts`, `.tsx`) files.
- Extracts:
  - Python `import` and `from ... import ...` statements.
  - `pip install` commands.
  - JavaScript `import ... from ...` statements.
  - `require(...)` calls.
  - `npm install` / `npm i` commands.
- Checks package names against PyPI and npm.
- Filters Python standard-library modules and Node.js built-in modules.
- Normalizes common Python import names such as `PIL`, `sklearn`, `cv2`, `yaml`, and `bs4`.
- Detects names that closely resemble popular packages.
- Produces a risk score from `0` to `100` and a risk level.

## Risk Levels

| Risk level | Score | Meaning |
|---|---:|---|
| MINIMAL | 0-19 | The package appears valid and has no significant warning signals |
| LOW | 20-39 | Minor warning signals detected |
| MEDIUM | 40-69 | Suspicious package name or metadata |
| HIGH | 70-100 | Strong indication that the package may be hallucinated |

Risk points are added for:

- A package that is missing from its registry: `60` points.
- A name similar to a popular package: `30` points.
- A package less than 30 days old: `20` points.
- Missing repository metadata: `10` points.

## Installation

Requires Python 3.10 or newer.

```bash
git clone https://github.com/reemnii/slopguard.git
cd slopguard
python -m pip install -r requirements.txt
```

## Command-Line Usage

Scan a Python file:

```bash
python cli.py test.py
```

Scan a JavaScript file:

```bash
python cli.py test.js
```

Example output:

```text
SlopGuard Scan Results
------------------------------------------------------------
requests                 PyPI   Risk:   0/100 [MINIMAL]
requets                  PyPI   Risk:  90/100 [HIGH]
   - Package does not exist in registry
   - Name similar to requests (92.3% match)
------------------------------------------------------------
1 high- or medium-risk package(s) detected.
```

The CLI prints package, registry, risk score, risk level, and any reasons for the score. It does not modify the scanned file.

## Python API

```python
from scanner.scanner import scan_code

code = """
import requests
import requets
"""

results = scan_code(code, ".py")

for result in results:
    print(result["package"], result["risk_score"], result["risk_level"])
```

Use `.js`, `.jsx`, `.ts`, or `.tsx` as the file extension when scanning JavaScript or TypeScript code.

## Experiment Tools

The `experiment/` directory contains tools for generating AI code, scanning the generated packages, and evaluating scanner performance.

### Run an experiment

Create a `.env` file in the project root. Configure one provider:

```dotenv
# Gemini
LLM_PROVIDER=gemini
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-3.6-flash

# Or Groq
# LLM_PROVIDER=groq
# GROQ_API_KEY=your_groq_api_key
# GROQ_MODEL=openai/gpt-oss-20b
```

Run:

```bash
python experiment/run_experiment.py
```

This writes generated responses to `experiment/responses.json` and package scan results to `experiment/results.csv`.

### Analyze experiment results

```bash
python experiment/analyze_results.py
```

### Evaluate the scanner

```bash
python experiment/evaluate_scanner.py
```

The evaluation script uses `experiment/evaluation_cases.json` and reports true positives, true negatives, false positives, false negatives, precision, recall, and F1 score.

## Limitations

Run the offline regression suite with `python -m unittest discover -s tests -v`. The live evaluation command above also requires access to PyPI and npm; its small case set is a smoke test, not a general accuracy guarantee.

- Registry checks depend on internet access to PyPI and npm.
- Registry or network errors produce an `UNKNOWN` risk level with `exists` and `risk_score` set to `None`; retry these checks when registry access is available. Evaluation excludes unverified cases from its metrics.
- Name similarity is limited to a small curated list of popular packages.
- Package existence alone does not prove that a package is legitimate or safe.
- SlopGuard is a heuristic tool and should be used as a warning aid, not the only security check.
